# 🎮 Discord Pokémon Bot

Bu proje, Discord üzerinde eğlenceli bir **Pokémon mini oyunu** oynamanıza olanak sağlar.  
Kullanıcılar kendi Pokémonlarını oluşturabilir, onları besleyebilir ve diğer oyuncuların Pokémonlarıyla savaşabilir.

---

## 🚀 Özellikler
- Rastgele Pokémon oluşturma (standart, **Wizard** veya **Fighter** türleri).
- Pokémon hakkında bilgi alma (isim, HP, güç, tür).
- Pokémon’u besleyerek sağlık puanını artırma.
- Diğer oyuncuların Pokémonlarına saldırma.
- PokeAPI üzerinden Pokémon görsellerini çekme.
- Discord bot komutları ile etkileşim.
